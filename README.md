# YYZ AVOP DA Practice

A static web app. Open `index.html` in a browser; no installation is required. The app does not bundle the GTAA map or manual figures. Map questions link to GTAA’s official April 2024 site map in a separate tab, and the three diagram questions use original simplified illustrations.

## Format

- Mock Exam: 26 multiple-choice airside-rule questions, three diagram questions, and 20 map-location checks under Question 30.
- The main screen links directly to GTAA’s official April 2024 site map. The mock exam still includes all 20 map-location checks within Question 30.
- Questions, answer options, and map locations are randomized each session.
- Passing requires all map locations correct and no more than three errors on the other questions.
- Progress and scores are not saved.

## Difficulty and source basis

The linked Fellow Drivers quiz uses concise recall and application questions, four or more answer choices, definitions, and diagram-based right-of-way items. This app follows a comparable short-question format and mixes rule recall with applied scenarios while preserving the 30-question structure requested for this practice exam. Questions were independently rewritten from the supplied practice notes and checked against the supplied Airport Traffic Directives – AVOP DA (2026). The home screen uses a clean blue gradient. The map quiz uses a custom, unlabeled schematic illustration. The three exam diagram items use simplified, original illustrations of apron passenger paths and vehicle-corridor right-of-way.

This is an unofficial personal study aid, not an exam replica or a GTAA-approved product. The map-location tolerance is approximate for practice. The April 2024 site map may not reflect later changes. Follow the latest official directives and airside signs.
