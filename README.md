# YYZ AVOP DA Practice

A static web app. Open `index.html` in a browser; no installation is required. The app includes the user-provided YYZ map JPEG for the map-click test and the two user-supplied diagram images for apron-marking and right-of-way questions. Map questions link to GTAA’s official April 2024 site map in a separate tab.

## Format

- Mock Exam: 26 multiple-choice airside-rule questions, three diagram questions, and 20 map-location checks under Question 30.
- Map Test Only: a standalone randomized 20-question map session using the uploaded YYZ map. Click approximately near the requested area; a location-dependent tolerance radius is used. It includes Taxiway & Apron Entrance codes AD, AE, AF, AG, AT, AJ, AK, AL, AM, DQ, DP, DR, DT, and DV, plus Terminal 3, deicing/cargo areas, North and South Service Roads, and the Infield Concourse. Highway questions are excluded.
- The mock exam includes the same 20 location checks as Question 30.
- Question order and choices, and map-location order, are randomized each session.
- Passing requires all map locations correct and no more than three errors on the other questions.
- Progress and scores are not saved. The home screen Update button checks the deployed version and reloads when a newer version is available.

## Difficulty and source basis

The linked Fellow Drivers quiz uses concise recall and application questions, four or more answer choices, definitions, and diagram-based right-of-way items. This app follows a comparable short-question format and mixes rule recall with applied scenarios while preserving the 30-question structure requested for this practice exam. Questions were independently rewritten from the supplied practice notes and checked against the supplied Airport Traffic Directives – AVOP DA (2026). The home screen uses a clean blue gradient. The map quiz uses a custom, unlabeled schematic illustration. The apron-marking question displays `sample/Diagram_01.jpeg`; right-of-way questions display `sample/Right of way.jpeg`.

This is an unofficial personal study aid, not an exam replica or a GTAA-approved product. The map-location tolerance is approximate for practice. The April 2024 site map may not reflect later changes. Follow the latest official directives and airside signs.
